## Run Locally (At your own risk)
1- **Download Processing:** Ensure you have [Processing 4+](https://processing.org/download) installed

2- **Clone the repo**
```bash
  git clone https://github.com/Blackslot26/OutOfBounds
```
3- **Install Libraries:** Open the Processing IDE and go to Tools > Add Tool.... Search for and install:
- Sound (by The Processing Foundation). 
- Video (by The Processing Foundation).

4- **Run:** open ```main.pde``` and press the run button.

5- **Final Step:** Pray to whatever deity you believe in that it doesn't explode.


## FAQ

#### __Is the game finished?__

- NO. The game is nowere near to be finished and 40% of the code is not really implemented.

#### __The game crashes randomly (Buffers error)__

- Yeah, that might happen... just close it and open it again and pray it doesn't happen again.

#### __The levels are unbeatables__

- The objects of the levels are programmed based on your monitor resolution and things like the scale or a different resolution can make some levels unbeatables. If you play with 1920x1080 with 125% scale it should work fine.

#### __Do we plan to fix the game?__

- Fuck no. This is a time capsule of our first-year suffering and it shall remain untouched for eternity.
